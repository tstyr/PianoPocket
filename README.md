# PianoPocket release artifacts

Tested distribution files for PianoPocket 0.2.0-alpha. Source is on main. The APK is debug-signed and ARM64-only.

No Pianobook/Helsinki audio, IR, images or original presets are included. PocketFixture.zip contains original synthetic test sounds under the MIT license. SHA256SUMS-0.2.0.txt lists checksums. Galaxy S26 hardware and end-to-end latency remain unverified.

Direct GitHub Release asset uploads returned an authentication error, so release descriptions link to these distribution files.
