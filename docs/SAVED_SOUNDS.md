# 音源ごとの設定とお気に入り（0.7.0）

音源パネルに「お気に入り」「現在の音を保存」「初期値」を追加。マイクのgroup音量、XMLコントロール（音源Masterを含む）、エフェクトパラメータ・有効／無効、IRメニュー、Output、最大サンプルボイス数を保存します。変更は350msのdebounce後に専用ワーカーで自動保存。音源切替・背景移行・通常終了時にも保存し、同じ音源を読み込むと復元します。強制終了直前350ms以内の操作は保存に間に合わない場合があります。

名前付きお気に入りは音源ごとに最大32件、40文字。同名は保存ボタンの説明どおり置換。呼び出すと音源を再準備するため再生を停止し、短いロードが生じます。削除・初期値は確認ダイアログを使います。初期値はXML設定とOutput0.7・共通の発音上限を使い、お気に入りを保持します。音源フォルダー削除時は付属する各プリセットの保存設定も削除。

音源IDと構成のSHA-256をファイルキーにし、別音源へ設定を流用しません。マイク・コントロール範囲・FX種類・IR選択肢などの構成が変わると別保存領域を使い、旧構成の設定は保持します。現在のIR選択やコントロール値は構成ハッシュに入れず、選び直しても同じ保存領域を使います。

アプリ専用領域へのversioned binary、最大128KiB、コレクション上限・有限数・範囲・EOFを検査。tmpへ書いてfsync／renameで置換。壊れたデータは初期値復旧の警告を出し、元データを.brokenへ退避します。音源XML・WAV・IRそのものや診断モードを書き換えず、外部への送信も行いません。
