# トラック別の音源

MIDIを選び、「その他 → 練習・メトロノーム」を開きます。トラック欄の「音源」からインポート済みの音源・SoundFont音色を選べます。「主音源を使う」で解除します。割り当ては曲ごとに保存されます。

## 動作

主音源に加えて8種類までの音源を読み込めます。同じ音源は複数トラックで共有します。音源ごとのマイク音量、ベロシティ曲線、保存したエフェクト・楽器Master設定を反映し、エフェクトチェーンは音源ごとに処理します。全体の出力音量は主音源のOutputです。

同じMIDIチャンネル・音程でもノートオフはトラックに対応します。CC・ベンドは元のMIDIチャンネルに従って共有します。奏法と排他グループは音源ごとに分けます。画面鍵盤とリアルタイム入力は主音源を使います。

音声・動画の書き出しにも割り当てを反映します。MIDIファイルや外部MIDI出力には元のチャンネル・Bank Select・Program Changeを保存・送信します。サンプルやエフェクトはMIDIファイルへ含めません。GMの自動音色選択は行いません。

## 上限

- 主音源＋追加8種類、グループ・マイク合計256。
- 全音源で設定したサンプルメモリ上限と発音数を共有します。
- 同じ入力元・MIDIチャンネル・音程の押鍵は最大16件を管理します。上限を超える場合は古い押鍵を置き換えます。
- 複数の大容量音源やIRを使うと準備時間・メモリ・CPU負荷が増えます。上限を超えた割り当ては拒否します。
- 音源変更時は演奏を一旦止めて準備します。シーク前から続いていたノートの途中波形は復元しません。

音源を削除した場合、その音源の割り当てを解除します。旧版の曲設定も読み込み、音源を指定していないトラックには主音源を使います。

## 検証

JVMテストで音源共有、ルート割り当て、旧Decent Samplerマッピング・SFZカーブの維持、曲設定の保存と旧版移行、上限の拒否を確認します。ネイティブテストで同じチャンネルと音程の離鍵分離、左右の音源、エフェクト分離、キー切替、音声処理内の動的確保0を確認します。

MultiBankDeviceTestは4列のJNIタイムラインによる実際のWAV書き出しを検査します。Android端末テストはコンパイル済みですが、開発環境に端末がなく未実行です。

```sh
./gradlew connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=dev.pianopocket.MultiBankDeviceTest
```
