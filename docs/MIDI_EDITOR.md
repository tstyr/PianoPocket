# MIDI編集

MIDIライブラリの曲カードにある「⋮ → 編集」、または演奏画面の「その他 → MIDIを編集」から開きます。録音したMIDIも編集できます。縦・横の両画面に対応しています。

- 音符をタップして選択。短い音符は周囲も選択範囲になります。
- 選んだ音符をドラッグして位置・音程を変更。
- 背景をドラッグして移動、2本指で時間軸と音域を拡大・縮小。
- 下のボタンで位置・長さ・半音を調整。強さはスライダーで変更。
- 「揃える」で選んだ音符の開始と終了をグリッドに合わせます。1/4・1/8・1/16を選択でき、「吸着」でドラッグにも適用できます。
- トラックを絞ると、重なった音符を選びやすくなります。
- 上部の矢印で取り消し・やり直し。履歴は64操作までです。

「コピー保存」で別のMIDIとしてライブラリに追加します。元のMIDIは上書きしません。曲に保存していた音源・トラック設定もコピーし、再生は停止状態で開きます。

編集対象は転調前のMIDIです。ペダル・テンポ・Program Change・SysEx・メタ情報は保持し、音符の長さは鍵盤を離すまでの長さを扱います。ペダルの残響を音符の長さに含めません。未変更のノートイベントは保持します。変更した音符は最低1 tickの長さになります。同じチャンネル・音程を異なるトラックで使う場合も、トラックごとにノート終了を対応させます。

音符の新規追加・範囲選択・複数音の一括編集・ペダルやテンポの編集・編集途中の自動保存は未対応です。編集画面では試聴せず、コピー保存後に演奏画面で再生できます。アプリのプロセスが終了すると未保存の編集は失われます。

## 検証

自作MIDIによるJVMテストで、トラック別のノート対応、ペダルを含む長さ、音程・強さ・位置の変更、元イベントの保持、保存後の再解析、削除・取り消し・やり直し、範囲上限、表示インデックスを検証しています。AndroidビルドとLintを実施。開発環境にはAndroid実機・エミュレーターが接続されていないため、タッチ操作は実機での確認が必要です。

実機では、短い音符の選択、ピンチ後のドラッグ、複数トラックの同音程、縦横切り替え、破棄確認、コピー保存後の再起動・再生を確認してください。
