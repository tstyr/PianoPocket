# 書き出し音量

書き出し画面の「音量を自動調整」は初期状態でオンです。WAV・FLAC・MP3・M4A・MP4・MOVの音声に適用します。設定は次回も保持します。MIDIには適用しません。

音声をFloat32で生成し、残響を含めた全体のピークを調べてから、左右共通の一定倍率で調整します。音符ごとの強弱・左右のバランスは保ちます。コンプレッサーで曲の強弱を潰す処理や、LUFSを揃える処理は行いません。

- WAV・FLACは−1 dBFS、非可逆形式は−2 dBFSを目安に余裕を取ります。
- 増幅は最大+12 dB。−60 dBFS未満のほぼ無音のファイルは増幅しません。
- サンプル間のオーバーシュートを3点の三次補間で推定し、必要に応じて倍率を下げます。BS.1770規格のTrue Peak測定ではありません。
- 16/24bitへの変換はディザを加え、Float32から一度だけ整数化します。完全な無音はゼロのまま保持します。
- 再生時の音量は変更しません。音源・エフェクト段階の歪みを除去する機能ではありません。

MP3/AACを再生したときのピークはエンコーダーとデコーダーでも変わります。非可逆変換後の最大値を保証する機能ではありません。

全体を読むため書き出し時間と一時保存領域が増えます。メモリは64KiB単位の読み書きで一定に保ち、進捗表示・キャンセル・容量確認・一時ファイルの削除に対応します。動画の5秒プレビューも同じ設定を使いますが、プレビューの倍率はその5秒の範囲から計算するため、曲全体と異なる場合があります。

## 検証

自作のFloat32 WAVによる自動テストで、左右比・強弱の保持、16/24/32bit保存、増幅上限、無音、補間ピーク、非可逆用ヘッドルーム、キャンセル時の削除、不正値、AAC入力用PCM16の読み込みを確認しています。追加のホスト検証では、実際のFloat32 `fmt` / `fact`チャンクを持つ自作和音から全3ビット深度に変換し、24bit出力を本番のFLAC・MP3エンコーダーに渡します。

```sh
./gradlew verifyNormalization -PnormalizationOutput=/tmp/pocket-normalization
build/native/codec_probe /tmp/pocket-normalization/adjusted-24.wav /tmp/pocket-normalization/encoded
```

AndroidのAAC・動画エンコーダーとの実機検証は未実施です。
