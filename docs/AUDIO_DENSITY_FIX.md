# 多層音源の発音抜け・ストリーミングノイズ修正（0.5.0）

1 MIDIノートが複数マイク・クロスフェードで複数のサンプルボイスを使用します。旧上限80/128は鍵数ではありません。新規ノートのレイヤーが互いをスティールする不具合を修正し、既定512・最大1024サンプルボイスに変更しました。旧設定は一度512以上へ移行します。タグ別polyphonyは未対応で、XML値をサンプルボイス上限へ自動適用しません。有限の上限に達すると古い／リリース中のボイスを優先して減らします。

固定256ページのLRUをメモリ予算に応じて256〜8192ページへ変更。4候補のハッシュ検索、先読み要求の重複抑制、現在必要なページの優先読み込みにより音声コールバック内の探索・要求負荷を削減しました。ページ欠落時には直前値からフェードし、取得時に復帰します。自然なサンプル終端・スティール・上限変更にも短いフェードを使用します。コールバックにファイルI/O・動的確保・重いロックは追加していません。

## 検証

- Native tests PASS: 6層のノートが同一ノート内で奪い合わないこと、80鍵×6層=480ボイスを既定512で欠落なく開始すること、32/80/128/512/1024上限、350サンプルのキャッシュ、重複要求、メモリ予算、読み込み失敗時の波形ジャンプ、コールバック内動的確保0。
- AddressSanitizer / UndefinedBehaviorSanitizer PASS。
- 利用者所有の実Helsinki 1967 XF v1.6マッピングでホスト上の実時間ペース4秒／48kHz／80鍵／512ボイス／256MiBテスト: 発音開始欠落0、スティール0、キャッシュミス0、読み込みエラー0、要求欠落0、キャッシュ7502ページ。最大ホスト処理時間3.75604ms。端末の遅延・CPU性能を示す値ではありません。私有サンプルは配布しません。

実機／イヤホン未接続。端末のDSP負荷・ストレージ・XRun・出力経路で残るノイズは別途確認が必要です。設定のスティール／キャッシュミス／要求欠落／読み込みエラーで切り分けできます。過負荷時には上限を下げ、バッファを増やしてください。
