# PianoPocket 0.4.5-alpha — 左下FPS表示

設定からFPS表示をオン／オフし、演奏画面の左下に小さく表示。設定を保存します。表示はWindow FrameMetricsで得た描画フレームの実測値で、画面の公称HzをFPSとして表示しません。

Androidビルド・Lint・47 JVM tests・APK署名と16KiB整列を確認。実機／エミュレーター未接続。FPS表示・端末上の実測値は実機未検証。120Hz更新は次の機能として実装します。
