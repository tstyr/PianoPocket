# PianoPocket 0.4.6-alpha — 最大120FPSの表示更新

設定に30 / 60 / 90 / 120FPSの上限を追加し保存。ディスプレイのvsyncに合わせてロール・鍵盤の状態を更新し、対応する表示モードを要求します。既定60FPS。FPS表示は引き続き実測描画フレーム数です。

Androidビルド・Lint・48 JVM tests・APK署名と16KiB整列を確認。実機／エミュレーター未接続。120FPSを保証しません。対応Hz・負荷・省電力・OSの選択に依存。実機の滑らかさと音声への影響は未測定。
