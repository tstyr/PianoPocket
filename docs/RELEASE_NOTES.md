# PianoPocket 0.12.0 — 待機練習とメトロノーム

- 必要な鍵盤を押すまで曲が待つ練習モードを追加しました。画面鍵盤とUSB / Bluetooth MIDIで使えます。
- 両手・左手・右手と対象トラックを選択できます。練習しない側は伴奏として再生します。
- 次の音を黄色い文字と鍵盤マーカーで案内します。
- テンポ・拍子に追従するメトロノームを追加。MIDI未選択でも使用でき、BPMと音量を保存します。
