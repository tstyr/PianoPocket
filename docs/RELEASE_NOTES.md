# PianoPocket 0.13.2 — ピアノアイコンから音源を選ぶ

- ピアノアイコンを押すと、MIDIライブラリ・音源ライブラリを選べます。演奏画面から、インポート済み音源や追加ダウンロードへ直接進めます。
- 演奏・ライブラリ・設定で同じ選択メニューを使用。小さい画面でもピアノアイコンを表示します。
- 再生バーの48dpの高さを維持。狭い画面の全音停止は「その他」から利用できます。
