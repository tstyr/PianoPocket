# PianoPocket 0.17.0 — 曲の設定を自動保存

曲ごとに音源、転調、再生速度、A–Bリピート、鍵盤の表示範囲、トラックの表示・ミュート、再開位置を保存します。別の曲を選んだりアプリを再起動したりしても、停止状態で復元します。

READMEと過去のリリース説明を、使い方・変更点・ダウンロード先を中心に整理しました。
