# 音源に応じたキャッシュ

設定のメモリ予算は上限です。WAVの常駐する先頭部分を除き、音源全体を保持するのに必要なページ数だけを確保します。小さな音源は最低32ページ（約1MiB＋管理領域）、大容量音源は設定予算内で最大8192ページを使います。オフライン書き出しは最大512ページです。

ページサイズと補間処理、LRU、先読み、キャッシュ欠落時のフェードは維持しています。確保とサイズ計算は音源準備時に行い、演奏中にはメモリを再確保しません。

内蔵ピアノのような小規模な音源で、設定予算分を常に確保する必要がなくなりました。設定画面のサンプル常駐量で実際の使用量を確認できます。表示は先頭波形とキャッシュで、UIやDSPを含むプロセス全体の使用量とは異なります。
