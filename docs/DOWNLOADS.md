# 高品質ピアノの追加ダウンロード

音源ライブラリの「Pocket Upright HQ」から取得します。約105MiBの通信と、展開用に約600MiBの空き容量が必要です。ダウンロード後は「高品質ピアノを選択」で読み込みます。軽量版や利用者が追加した音源も引き続き使えます。

## 音源

Pocket Upright HQは、同梱版と同じVSCO 2 Community Edition / Upright Pianoの録音を使用します。

| 項目 | 軽量版 | HQ版 |
| --- | --- | --- |
| 収録キー数 | 12 | 23 |
| ベロシティ | 3段階 | 3段階 |
| サンプル数 | 36 | 69 |
| 形式 | 44.1kHzステレオPCM16 | 44.1kHzステレオPCM24、FLAC可逆圧縮 |
| 残響 | 最大12秒＋末尾フェード | 元録音の全長、最大約28.6秒 |
| 取得 | APKに同梱 | 約105MiBを任意ダウンロード |

録音: Simon Dalzell / Ivy Audio。配布: Versilian Studios / Sam Gossner。[元音源](https://github.com/sgossner/VSCO-2-CE/tree/440300901dfe9275fd84e0b7763af1f8443ae62e)、CC0 1.0 Universal。元のレイヤー音量に共通の音量補正を加えています。専用リリースサンプルやラウンドロビンはありません。SFZ、元ファイル・変換後ファイルのハッシュ、出典、CC0全文は配布ZIPに入っています。Pianobook音源は含みません。

## サーバー不要の配布

データはGitHubの公開 `release-artifacts` ブランチに置いた静的ファイルです。個人サーバー、APIキー、アカウント、アプリ内課金は不要です。105MiBのZIPはGitHubの1ファイル上限を超えるため、40MiB以下の3つのファイルへ分割しています。アプリ内で順番に検証・読み込みするので、利用者が結合する必要はありません。

APKの [catalog](../app/src/main/assets/download-catalog.json) に配布コミット・HTTPS URL・正確なサイズ・各ファイルとZIP全体のSHA-256を固定しています。取得先の変更や新しいパックにはアプリの更新が必要です。実行コードやプラグインを取得・実行する機能ではありません。

通信するのは利用者が「ダウンロード」を選んだときだけです。演奏・録音・書き出しはオフラインで使え、個人の音源や演奏を送信しません。通知が許可されていれば、背景でも進行とキャンセルを確認できます。OSが処理を終了した場合は、再試行して途中から再開します。

## 検証・保存

- HTTPSとGitHub配布ホストだけを許可し、転送先にも同じ制限を適用します。
- 転送サイズを固定し、正しいContent-Rangeの場合だけ追記します。Range非対応の応答ではファイルを最初から書き直します。
- 既に取得した部分を保持し、各ファイルとZIP全体のSHA-256が一致した後だけインポートします。
- ZIPは既存のパス・ファイル数・展開サイズ・圧縮率の制限を適用し、一時フォルダーから確定します。中断した別処理が生きている間、その一時フォルダーは削除しません。
- サンプル取得は専用の背景ワーカー、ライブラリへの追加は既存の単一ワーカーで順序付けます。演奏中の音源は勝手に切り替えません。
- 取得が完了するとダウンロードキャッシュを削除します。音源削除では展開済みWAVも削除し、選択中だった音源のRAMも解放します。

FLACは読み込み時に一度WAVへ展開します。ライブラリの容量表示はそのWAVも含みます。新しい音源を選ぶ際の進行は「サンプル準備」で確認できます。

## 再生成

Python 3とホストのffmpeg / ffprobeを用意します。

```sh
python tools/prepare_optional_piano.py \
  --cache /tmp/piano-source \
  --output /tmp/pocket-upright-hq \
  --distribution /tmp/pocket-upright-hq-parts
```

ビルド時に105MiBの追加音源を取得する必要はありません。通常のAPKには軽量版と固定catalogだけが入ります。

## 確認結果

公開した3ファイルをGitHubから再取得し、サイズ・SHA-256の一致を確認しました。69 FLACのCRC / MD5と24bitステレオの復号、本番SFZパーサーの69リージョンを確認。ホスト上で発音・同時発音を確認しています。

自動テストで新規取得、検証済みキャッシュ、206再開、Range非対応、キャンセル後の再試行、破損ファイル、ZIP全体のハッシュ、誤ったRange、危険なパス・HTTP URLを確認。Android端末のフォアグラウンド取得・通知・回線切替は未検証です。ZIP追加・再起動・FLAC準備・別Repository生成中の一時フォルダー保護の端末テストはコンパイル済みで、実行は未実施です。
