# 背景書き出し・プレビュー（0.9.0）

動画／音声／MIDIを書き出すと、ExportServiceがジョブを保持します。ホームへ移動、画面回転、Activity／ViewModel破棄後もサービス側のスナップショットで処理する構造です。進行・キャンセルを通知とアプリ内に表示。Android 13以降は初回書き出し時に通知許可を選択し、拒否してもアプリ内の操作で利用できます。設定 → 書き出し通知の設定から後で変更できます。許可なしでは通知欄の表示・キャンセルは利用できません。

サービスは35以降のmediaProcessing、旧OSのdataSyncタイプ。期限付きpartial WakeLockで画面オフ時にもCPUを保持し、完了・失敗・破棄時に解放します。OSの6時間制限を受けたらキャンセルします。省電力・メーカー独自制限・プロセス終了・強制停止を超えて継続を保証しません。START_NOT_STICKYで、プロセスが失われたジョブを自動再開する実装ではありません。

## 5秒プレビュー

書き出しダイアログで動画形式を選び「5秒プレビュー」。元MIDIの現在位置から最大5秒＋1秒tailを現在の音源で生成し、アプリ内のVideoViewで再生します。終端の位置なら先頭から生成。開始前のCC／Pitch Bendと鳴っているノートを再構築しますが、長く鳴ったサンプルの途中波形を完全に再現するseekではなく、該当サンプルを再発音する近似です。

プレビューはMP4で、選択した解像度・FPS・AACレートを使います。本番のMP4／MOV選択、音質・tail・動画設定は保存し、閉じて演奏音源を再準備したら同じ選択の書き出しダイアログへ戻ります。プレビューのMP4はcache/previews内だけに置き、範囲を限定した非公開FileProviderで再生。外部アプリやGitHubに自動送信しません。閉じた時・新しいジョブ開始時・次のプロセス起動時に不要なファイルを削除。

## 進行と残り時間

音声生成、AAC／圧縮、映像生成、保存先コピーを区別します。残り時間は**現在の工程**の最近15秒／最大30観測から計算し、1秒・2%以上の進行が得られるまで表示しません。工程変更・逆行・未取得はリセット。未実行の後続工程や瞬間の速度から全所要時間を断定しません。端末・ストレージ・温度で推定値は変動します。

JNIのロード／書き出しはプロセス所有の単一actorで順序付け、Activityのワーカーを終了してもジョブを消しません。演奏を停止し、演奏bank・FXをaudio callback外で解放して書き出しメモリを抑えます。終了後に保存した音源設定と曲内位置のCCを復元。プレビューを閉じるまで演奏は停止します。全処理は現在の音源設定のスナップショットを使い、練習用の速度・区間・ミュートは書き出しに適用しません。

キャンセル・失敗時は一時PCM／AAC／動画を削除し、保存途中のSAFファイルの削除を試行。providerが削除を拒否すると途中の保存先が残る場合があります。成功フラグは処理完了でだけ設定し、エラー文を成功判定に使いません。
