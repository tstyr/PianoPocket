# 練習機能（0.8.0）

︙ → 速度・リピート・トラック。速度は0.25／0.5／0.75／1／1.25／1.5／2倍。MIDIの時間進行をC++サンプル時計で変え、WAVのピッチ・再生ステップは変えません。シーク・ロールは元の曲の時刻を表示し、テンポ変化も同じ倍率になります。

A／Bボタンは現在の曲内位置を設定。A–Bリピートは最短0.1秒、Bを含まない区間です。繰返し時はファイル再生ボイスを5msでリリースし、A前のCC7／CC11／CC64・Pitch Bendを事前構築した固定スナップショットから復元します。音声コールバックで元の全MIDIを走査・確保せず、UIポーリングにも依存しません。外部MIDI／画面鍵盤のチャンネルは維持。A前に開始した長いノートの途中波形は再構築しないため、区間始端は弾き始めを選ぶのがおすすめです。

トラック別表示オン／オフ、ノートミュート。ミュートしたノートは不透明な灰色でロールに残し、鍵盤の自動強調から除外します。表示オフでも音は鳴ります。ミュートはNote On／Off（velocity0を含む）を対で除き、共有チャンネルのペダル・音量CCを保ちます。複数トラックが同じチャンネルを使う場合、CCの影響を独立できません。

トラックミュートと区間変更は準備のためストリームを短く再開することがあります。ミュート変更時は元の位置・速度・ループ・再生状態を復元しますが、シーク前に開始したノートは途中から再構築しません。練習設定はセッション内で使い、別MIDIを選ぶと初期化。書き出しは元のMIDI全体・通常速度・全トラックを使い、練習設定は適用しません。
