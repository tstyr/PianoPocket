# 練習機能（0.8.0）

︙ → 速度・リピート・トラック。速度は0.25／0.5／0.75／1／1.25／1.5／2倍。MIDIの時間進行をC++サンプル時計で変え、WAVのピッチ・再生ステップは変えません。シーク・ロールは元の曲の時刻を表示し、テンポ変化も同じ倍率になります。

A／Bボタンは現在の曲内位置を設定。A–Bリピートは最短0.1秒、Bを含まない区間です。繰返し時はファイル再生ボイスを5msでリリースし、A前のCC7／CC11／CC64・Pitch Bendを事前構築した固定スナップショットから復元します。音声コールバックで元の全MIDIを走査・確保せず、UIポーリングにも依存しません。外部MIDI／画面鍵盤のチャンネルは維持。A前に開始した長いノートの途中波形は再構築しないため、区間始端は弾き始めを選ぶのがおすすめです。

トラック別表示オン／オフ、ノートミュート。ミュートしたノートは不透明な灰色でロールに残し、鍵盤の自動強調から除外します。表示オフでも音は鳴ります。ミュートはNote On／Off（velocity0を含む）を対で除き、共有チャンネルのペダル・音量CCを保ちます。複数トラックが同じチャンネルを使う場合、CCの影響を独立できません。

トラックミュートと区間変更は準備のためストリームを短く再開することがあります。ミュート変更時は元の位置・速度・ループ・再生状態を復元しますが、シーク前に開始したノートは途中から再構築しません。練習設定はセッション内で使い、別MIDIを選ぶと初期化。書き出しは元のMIDI全体・通常速度・全トラックを使い、練習設定は適用しません。

59 JVM tests PASS。追加2 testsは両ノート端の除去、共有CC維持、トラック名・フォールバック。Native testsは速度ごとの元時計、異なる速度で同一オンセット波形（ピッチ維持）、ループ区間／B除外・A前サステイン復元・ライブ音声保護・極短区間拒否・無割当を確認。ASan/UBSan PASS。実Helsinki XF＋IRの10秒書き出し回帰も有限・非無音・残響・ミス0で成功（音声は非公開）。AndroidビルドとLint PASS。操作UI・切替クリック・長時間ループは実機未検証です。

## 待機練習・左右別・メトロノーム（0.12.0）

︙ → 練習・メトロノーム。「鍵盤で練習」をオンにすると、選んだ手・トラックのノートは自動再生せず、画面鍵盤または選択したMIDI入力で弾きます。もう片方の手は伴奏になります。「正しい鍵盤の入力を待つ」はC++の曲時計をノート開始位置で停止し、必要な音を押すと再開。間違った鍵盤・ファイル再生・ペダルでは先に進みません。和音は順に押しても成立し、繰返しの同じ音には新しい押鍵が必要です。次に必要な音を黄色い文字と鍵盤下端の黄色いマーカーで表示します。

左右は分割キー（既定C4、48〜72）による判定で、自動運指分析ではありません。交差する曲や明確に分かれたMIDIは対象トラックを指定してください。練習側のペダルは利用者の入力で操作します。10ms以内の近接したノートは和音としてまとめます。

メトロノームはサンプル時計で生成します。MIDIではテンポと拍子の変更・再生速度・リピートに追従。待機中は次の拍へ進まず、残った音声・FXの尾は維持します。MIDI未選択なら20〜300 BPMの4拍子で使用でき、BPMと音量は保存されます。書き出しへクリック音や練習設定は入りません。

JVMテストで左右・対象トラック・和音・テンポ変化・7/8拍子のアクセントを確認。C++で誤入力の待機、和音の残り音、USB相当と画面鍵盤の入力、ファイルによる誤解除の防止、繰返し・seek時の新しい押鍵、クリックのサンプル時計・pauseを確認しています。実機での操作・聴感確認は未実施です。
