# 音声診断（0.6.1）

出力経路とエフェクトを切り分けるための診断機能です。開発環境での実機試験は未実施です。

設定 → 音声の切り分けで通常／FXなし／テスト音を比較できます。テスト音は左右440Hz／660Hzの小さな自作サイン波で、サンプル・マイク・音源Master・FXの波形を使いません。Output音量と出力保護を使います。切替はスムージングし、テスト音へ入るとMIDI再生を止めます。通常に戻す、設定を閉じる、アプリを背景にする、全音停止で終了。診断モードは音源設定に保存しません。

FXなしは元のFX値を変更せず処理前の音へ切り替えます。元チェーンは残響・設定を保つため処理を続けるので、FXのCPU負荷を完全に除外するテストではありません。

60秒／最大120行の500msスナップショットを記録し「結果をコピー」で端末・OS・プリセット名・選択出力ID／利用可能出力・レート・バッファ・XRun・キャッシュミス・要求落ち・読み込みエラー・スティール・負荷・出力保護をコピーできます。共有は利用者の操作で行い、自動送信・ネット接続はありません。システム既定時の利用可能機器一覧は実際の出力経路の証明ではありません。

XRun未取得はunknown。経路再開などでカウンターが減った場合はリセットを別計数します。負荷・ピークは記録時の観測値で全瞬間の最大値や音響実測ではなく、数字だけで原因を断定しません。

診断コレクターはJVM tests、テスト音の有限・低音量・終了・コールバック内動的確保0はNative testsで確認。ASan/UBSan、Androidビルド、Lint PASS。診断UI・有線／USB／BluetoothのA/B比較は開発環境で実機未実施です。
