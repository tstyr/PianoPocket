# 低遅延／安定優先（0.6.2）

設定 → オーディオで低遅延（既定）／安定優先・自動を選択し、保存します。低遅延は手動の1〜8バーストを使います。安定優先は手動指定と4バーストの大きい方から開始。500msの監視でXRunが増えた場合、2秒以上の間隔で1バーストずつ最大8へ増やします。経路が許すバッファ容量までに制限します。演奏中は自動で縮小しません。音量・音源設定の操作とは独立です。

XRunが取得不可の場合、増加を捏造せず自動増量しません。再開によるカウンターリセットを不具合増加と扱いません。学習した大きさは同じ経路・指定値の再開で保持し、出力先や手動値の変更、モード変更で再設定します。OSが要求を拒否／丸める場合は設定画面の実framesを確認してください。

バッファ変更は非オーディオスレッドでOboe APIを使います。コールバックにロック・I/O・割当は追加しません。サンプル読み込みエラーや発音上限への万能な対策ではなく、バッファ増量で出力遅延が増えます。10ms以下を保証しません。

有界の増量・間隔・未取得・リセット・手動モード・ハードウェア上限はNative tests、ASan/UBSanで検証。AndroidビルドとLint PASS。端末上のXRun改善と遅延は実機未測定です。
